# المصروف الذكي | Masroof Smart

تطبيق Flutter جديد لإدارة المصروفات الشخصية في السعودية، بواجهة عربية RTL وإنجليزية LTR.

## بدء البناء على GitHub

لتحديث المستودع الذي رفعته سابقًا، فك ضغط حزمة التحديث وانسخ محتوياتها إلى مجلد المستودع عبر GitHub Desktop، ثم اعمل Commit وPush. افتح تبويب **Actions** وانتظر **Build Masroof Smart APK**. عند نجاح البناء نزّل `masroof-smart-release-apk` من قسم Artifacts. التفاصيل في `ابدأ-من-هنا.md`.

## الحالة الحالية

يتضمن المشروع لوحة مالية، عمليات يدوية، ميزانيات بفترة تبدأ بتاريخ تختاره، تقارير، قائمة بنوك مستقلة بمفاتيح تفعيل، وتخزينًا محليًا. يستورد رسائل البنوك المؤهلة عند فتح التطبيق أو العودة إليه بعد موافقة Android، ويقتصر البحث على البنوك المفعلة والرسائل بتاريخ بداية الميزانية أو بعدها. يستبعد OTP، ويحفظ معرف الرسالة لمنع التكرار، ويستخدم تاريخ الرسالة واسم التاجر والبنك وآخر أربعة أرقام عند توفرها. بيانات SMS لا تغادر الجهاز.

يتضمن التصدير CSV متوافقًا مع Excel وتقرير PDF عربي/إنجليزي مفصلًا بخط عربي مضمن. راجع `ابدأ-من-هنا.md` لمعرفة القيود والاختبارات المطلوبة على جهاز Android.

## الخصوصية

لا يطلب التطبيق بيانات دخول بنكية. قراءة SMS تتطلب موافقة Android، ويشرح التطبيق نطاقها قبل نافذة الصلاحية. الاستيراد محلي ولا يعمل في الخلفية؛ أسماء مرسلي البنوك وصيغ رسائلها تختلف، لذلك يلزم اختبارها على جهاز Android. لا يرفع التطبيق الرسائل إلى خادم.

خط PDF العربي Noto Sans Arabic من مشروع Google Noto، مرخص تحت SIL Open Font License 1.1؛ نسخة الترخيص مرفقة في `assets/fonts/OFL.txt`.
